# Avoid AI Writing (Standar Eliminasi Pola AI)
Diadaptasi dari [conorbronsdon/avoid-ai-writing](https://github.com/conorbronsdon/avoid-ai-writing).

Gunakan panduan ini untuk mengaudit dan menulis ulang teks agar tidak terdengar seperti hasil *prompting* AI atau template generik.

---

## 1. Aturan Format & Tipografi AI:
- **Zero Em Dashes (—)**: Hapus penggunaan tanda hubung panjang (*em dash* `—` atau `--`). Target: 0. Ganti dengan koma, titik, tanda kurung, atau pecah menjadi dua kalimat terpisah.
- **Bold Overuse**: Jangan menebalkan (*bold*) terlalu banyak kata/frasa di dalam kalimat. Maksimal satu frasa penting per bagian, atau tidak sama sekali.
- **Emoji di Heading & Bullet**: Dilarang menggunakan emoji di judul (`🚀`, `💡`, `⚙️`).
- **Excessive Bullet Lists**: Jangan memecah setiap ide menjadi daftar *bullet point* bertingkat jika kalimat mengalir (*prose*) lebih wajar dibaca.

---

## 2. Struktur Kalimat AI yang Terlarang:
- **Pola "Bukan sekadar X, melainkan Y" / "It's not X — it's Y"**:
  - *Larangan*: "Ini bukan sekadar alat angkat, melainkan revolusi ergonomi."
  - *Perbaikan*: Langsung nyatakan faktanya: "Alat ini mengalihkan beban hingga 50 kg dari punggung operator ke tabung vakum."
- **Pola Negasi Bertingkat ("The Multi-Negation Countdown")**:
  - *Larangan*: "Bukan soal kecepatan. Bukan soal harga. Ini soal komitmen keselamatan."
  - *Perbaikan*: Langsung ke inti argumen tanpa retorika dramatis.
- **Hollow Intensifiers (Kata Penguat Kosong)**:
  - Hapus kata: *genuinely, truly, quite frankly, to be honest, let's be clear, it's worth noting that, actually* (jika hanya penambah bobot kalimat).
- **Vague Endorsements ("Worth [verb]ing")**:
  - Hapus: *worth exploring, worth checking out, patut disimak, perlu Anda ketahui*. Berikan alasan faktualnya langsung.
- **Compulsive Rule of Three (Pola 3 Serangkai yang Dipaksakan)**:
  - Jangan memaksakan mengelompokkan selalu 3 kata sifat berima (misal: "Cepat, tepat, dan hemat"). Sebutkan spesifikasi aslinya.
- **Penutup Sok Puitis**:
  - Hapus kalimat klise di akhir: "Menatap masa depan intralogistik yang cerah", "Biarkan kenyataan itu meresap", "Hanya waktu yang bisa menjawab".

## 3. Daftar Kata Terlarang (Tier 1 AI Frequency Markers):

| Kata AI (Dilarang) | Pengganti Alami / Bahasa Manusia |
| :--- | :--- |
| **Delve / Delve into** | Pelajari, periksa, tinjau, lihat |
| **Landscape (metafor)** | Sektor, industri, bidang |
| **Tapestry / Mosaic** | Struktur, rangkaian, sejarah (sebutkan faktanya) |
| **Seamless / Seamlessly** | Lancar, tanpa kendala, mudah |
| **Robust** | Kuat, kokoh, andal |
| **Comprehensive** | Lengkap, menyeluruh |
| **Cutting-edge / State-of-the-art** | Terbaru, modern, berteknologi presisi |
| **Leverage (kata kerja)** | Gunakan, manfaatkan, terapkan |
| **Pivotal / Watershed moment** | Titik balik penting, perubahan |
| **Underscores / Highlights** | Menunjukkan, membuktikan |
| **Meticulous / Meticulously** | Teliti, presisi, berhati-hati |
| **Game-changer** | Mengubah metode kerja [X] (sebutkan spesifikasinya) |
| **Testament to** | Bukti nyata bahwa, menunjukkan |
| **Beacon / Paradigm** | Contoh, acuan, model |
| **Actionable / Impactful** | Praktis, konkret, berdampak langsung |
